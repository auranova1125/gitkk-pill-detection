# Kaggle 제출 기록과 진단 결과

대회 `ai15-level1-project`(평가지표 mAP@[0.75:0.95], 마감 2026-11-06 23:55 KST)에 낸 제출과
진단 제출의 결과를 정리한다. 실제 제출 CSV는 저장소에 올리지 않고 로컬
`outputs/kaggle_submissions/`에 보관한다. 제출 파일 생성은 프로젝트의 공통 통합 추론
경로를 사용했다.

## 핵심 결론

1. **Public 점수 = Public 정답에 있는 74종의 클래스별 AP 평균**이다(운영진 답변).
   정답에 없는 클래스는 계산에서 빠지고, Private도 같은 코드와 같은 74종으로 계산한다.
2. **val과 Public 사이에 큰 차이가 있다.** val은 약 0.92~0.95인데 Public은 약 0.58~0.62다.
   클래스 하나씩 제출한 진단에서도 AP가 약 0.5로 비슷하게 나타났다. 정답 공개 범위,
   평가 분할 또는 test 분포 차이가 후보지만 이 기록만으로 원인을 확정하지 않는다.
3. **현재 bbox 크기를 ±3% 조정하면 점수가 하락했다.** Public이 약 0.58에서 0.50으로
   낮아져 기존 bbox가 두 변형보다 평가 정답에 더 가깝다는 근거가 됐다. 다만 이 실험만으로
   전체 좌표 변환 과정이 완전히 옳다고 증명한 것은 아니다.
4. **뒤 순위 보험 박스와 박스 앙상블의 개선은 작고 일관되지 않았다.** 보험 박스는
   최대 +0.003, YOLO 중심 앙상블은 +0.0002, WBF는 -0.0002였다. Validation에서
   확인한 박스 정밀도 개선도 Public 점수 상승으로 이어지지 않았다.
5. **이번 제출 기록에서는 탐지기 변경에 따른 차이가 가장 컸다.** 같은 ResNet-50
   분류기를 연결했을 때 SSDLite320 0.588, YOLO11s 0.608, YOLO26s 0.618을 기록했다.
6. **최종 제출 후보는 YOLO26s 단독(0.61804, ref 58003762)이다.** 최종 선택은 Kaggle에서 직접 지정해야 한다.

## 아직 확인하지 않은 것

- val과 Public 차이의 정확한 원인. 정답 공개 범위, 평가 분할과 test 분포의 영향을
  현재 진단 제출만으로 분리하지 못했다.
- 학습·추론 코드와 결과 보고서는 저장소에 통합했지만, 실제 checkpoint와 제출 CSV는
  Git에 포함하지 않는다. 동일 제출을 재현하려면 보관된 가중치와 실행 설정이 함께 필요하다.
