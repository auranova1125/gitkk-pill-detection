# 탐지 데이터 코드 정리 기록

## 변경 목적

실행 시작점과 코드 역할을 설명하기 쉽도록 중복 검사를 모으고 표본 ZIP 생성 기능을 제거했습니다.
고정된 라벨·분할 목록·이미지와 팀원의 모델 코드는 변경하지 않았습니다.

## 변경 내용

| 변경 | 이유 |
|---|---|
| `preflight.py` 검사와 로더의 기록 검사를 `data_records.read_records`로 통합 | ID·분할·경로·박스 검사를 한곳에서 관리 |
| `detector_inputs.py`를 Dataset·DataLoader 역할로 축소 | 이미지 한 장이 배치가 되는 흐름을 설명하기 쉽게 구성 |
| 중복 배치 검증 함수 제거 | 팀원의 실제 입력 검증 함수 사용 |
| 자동 표본 선택·임시 라벨 생성·공유 ZIP 생성 제거 | 이미 공유한 4장으로 검사하면 충분함 |
| 기존 코드 해시 일치 강제 조건 제거 | 코드 개선 때마다 이미지 ZIP을 다시 만들 필요가 없도록 변경 |
| 표본 파일 해시 검사 유지, 현재 코드 해시는 새 보고서에 기록 | 데이터가 같은지와 어떤 코드로 실행했는지를 구분 |
| 잘못된 원본 bbox는 보정 대신 중단 | 오류 데이터를 고치지 않고 제외하는 기존 정책 유지 |
| 이미지 크기 불일치 오류 메시지 수정 | 존재하지 않는 record 키를 참조하던 부분 수정 |
| 노트북에서 실행 보고서를 직접 읽기 | 리뷰에서 검사 결과 위치와 내용을 바로 확인 |

데이터 모듈 Python 코드는 공백·주석 포함 1,338줄에서 814줄로 줄었습니다.
이 숫자는 코드 품질 판정이 아니라 변경 규모를 설명하기 위한 참고입니다.
기존 함수 경로 `detector_data.detector_inputs:build_detector_inputs`와 반환 순서는 유지했습니다.
기존 `smoke_bundle check/run` 명령은 짧은 검사 명령으로 연결하는 호환 코드입니다.
기존 `smoke` 명령은 이제 공유 표본으로 모델 연결까지 검사합니다. 파일 확인만 하려면 `smoke-check`를 사용합니다.
`loaders` CLI는 제거했으며, 전체 로더 준비는 `START_DETECTOR_DATA.ipynb`에서 수행합니다.

## 이번 코드에서 수행한 검사

- 합성 PNG·JSON·CSV를 사용한 자동 검사 20개 통과
- 파일 누락, ID 중복, annotation 연결 오류, 분할·개수 불일치, 그룹 중복 검출
- 좌표·면적·자료형 오류와 변경된 표본 파일 검출
- 검사 명령의 성공·실패 보고서 저장 확인
- 수정 전후 합성 표본의 이미지·박스 기록과 분할 해시 일치
- 적용 스크립트의 백업과 관계없는 Notebook·모델 파일 보존 확인
- Python 코드와 Notebook 코드 셀 문법 확인, Notebook 실행 출력 제거

자세한 결과: `detector_data_simplification_checks.json`

실행 환경에 PyTorch와 실제 데이터가 없으므로 이번 변경 코드의 실제 모델 연결 검사와 전체 데이터 검사는 수행하지 못했습니다.
사용자 환경에서 두 Notebook을 실행한 뒤 새 보고서를 공유해야 합니다.

## 이전 실행 근거

첨부된 `previous_shared_smoke_report.json`은 사용자가 제공한 변경 전 실행 보고서입니다.
CPU, 배치 2, Train 2장·8개 박스, Validation 2장·8개 박스입니다.
SSDLite 손실 계산·역전파·가중치 갱신 1회가 `passed`이며 체크포인트 저장은 없습니다.

이 기록으로 이번 변경 코드가 모델 검사까지 통과했다고 주장하지 않습니다.
새로 실행한 보고서를 `reports/shared_smoke_report.json`으로 공유해 구분합니다.
