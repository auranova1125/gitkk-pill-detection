## 학습 데이터와 중복

학습 패키지가 쓴 원본 사진(train+val)과 비교했다.

- 학습 패키지와 같은 파일명: 0장
- 학습 패키지에 있는 조합 그룹의 사진: 0장
- 픽셀 동일: 0장 → 제외
- 유사 (pHash ≤ 5): 198장 → 제외하지 않고 `near_dup_in_train=True`로 표시 (평가셋에 남은 crop 658개)

유사 사진은 조합(약 구성)이 다른 **다른 사진**이다. AI Hub는 알약을 정해진 자리에 놓고 찍어서, 같은 알약이 같은 자리·방향에 놓이면 사진 전체가 닮는다.
학습 패키지 val도 같은 기준(pHash ≤ 5)으로 빼지 않고 표시만 했으므로 같은 규칙을 따른다. 평가할 때 전체 점수와 표시를 뺀 점수를 함께 본다.

pHash 거리별 사진 수: {0: 10, 2: 40, 4: 148}. 쌍 목록: `data/classifier/aihub_val/duplicates_with_training.csv`
