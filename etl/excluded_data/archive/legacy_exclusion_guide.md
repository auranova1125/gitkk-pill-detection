# 데이터 제외 내역

AI Hub와 Kaggle Train 데이터를 검증하면서 제외한 이미지와 annotation을 정리한 자료입니다. 빠른 데이터셋 구성을 위해 확인된 오류를 수정하는 대신 해당 이미지 전체를 제외했습니다. Kaggle Test 이미지는 이 집계에 포함하지 않습니다.

## 1. 제외 원칙
- 오류가 확인된 이미지와 그 이미지에 연결된 모든 annotation을 학습·검증 라벨에서 제거했습니다.
- 오류가 없는 알약의 annotation도 같은 이미지에 있으면 함께 제외했습니다.
- 일부 이미지가 제외되어도 해당 클래스의 다른 정상 이미지와 annotation은 유지했습니다.
- 이번 검증에서 클래스 전체를 제외한 경우는 없습니다.
- 라벨과 분할 목록에서 제외한 것이며, 원본 이미지 파일을 폴더에서 삭제했다는 뜻은 아닙니다.

## 2. 1차·2차 제외 수량

1차는 AI hub 와 Kaggle 데이터 검증 과정에서 결정한 제외 내역입니다. 2차는 통합·분할 이후 추가로 확인한 bbox 오류 이미지 5장입니다.

| 데이터 | 검증 전 이미지 | 검증 전 annotation | 1차 제외 이미지 | 1차 제외 annotation | 2차 제외 이미지 | 2차 제외 annotation | 유지 이미지 | 유지 annotation |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| AI hub | 10,240 | 39,392 | 131 | 501 | 5 | 20 | 10,104 | 38,871 |
| Kaggle Train | 232 | 763 | 17 | 46 | 0 | 0 | 215 | 717 |
| 합계 | 10,472 | 40,155 | 148 | 547 | 5 | 20 | 10,319 | 39,588 |

두 차례를 합쳐 이미지 **153장**, annotation **567개**를 제외했습니다. 통합 데이터에는 약품 클래스 118종이 남아 있습니다.

## 3. 제외 사유

| 데이터 | 검토 단계 | 기록된 제외 사유 |
|---|---|---|
| AI hub | bbox 중복·중첩 검토 | 중복·중첩 후보 시각 검토 후 제외 결정 |
| AI hub | 3-6 | bbox 위치·크기 오류, 제품 정보와 외형·각인 불일치, 이미지 경계에서 알약이 잘린 사례 |
| AI hub | 4-1 | 표본 시각 검토에서 가느다란 영역에 놓인 잘못된 bbox 확인 |
| Kaggle Train | 2-3 | bbox 면적 불일치 |
| Kaggle Train | 2-4 | 이미지 범위 초과 |
| Kaggle Train | 2-6 | 동일 bbox 및 위치 오류 |
| Kaggle Train | 2-14 | annotation 누락 |
| AI hub | 6-3 추가 bbox 오류 검토 | bbox가 알약을 감싸지 않고 주로 배경을 포함하는 오류 |

위 표는 사유를 간추린 것입니다. 이미지별 사유의 원문은 `legacy_excluded_image_details.csv`를 기준으로 확인합니다. 통계 기준이나 유사 이미지 검사에서 후보로 나온 것만으로 자동 제외하지는 않았습니다.

아래 이름은 출처 접두사와 확장자를 뺀 원본 이미지 이름입니다. 실제 이미지 파일명은 상세 CSV에서 확인합니다.

| 원본 이미지 이름 | 오류 확인 클래스 | 오류 bbox 너비 × 높이 |

| `K-012420-016551-024850-027926_0_2_0_2_70_000_200` | K-016551 | 23 × 497 px |

각 이미지에 연결된 annotation 4개를 모두 제외하여 총 20개를 제거했습니다. 너비·높이는 오류 사례를 식별하기 위한 값이며, 이 값만으로 정상 여부를 판정하는 자동 기준은 아닙니다.

## 5. Train/Validation 반영 결과

추가 5장을 제외할 때 새로운 무작위 분할은 하지 않았습니다. 나머지 이미지의 기존 분할 배정과 ID는 유지했습니다.

| 분할 | 추가 제외 전 이미지 | 2차 제외 이미지 | 유지 이미지 | 추가 제외 전 annotation | 2차 제외 annotation | 유지 annotation | 약품 클래스 |
|---|---:|---:|---:|---:|---:|---:|---:|
| Train | 8,260 | 4 | 8,256 | 31,689 | 16 | 31,673 | 118 |
| Validation | 2,064 | 1 | 2,063 | 7,919 | 4 | 7,915 | 118 |
| 합계 | 10,324 | 5 | 10,319 | 39,608 | 20 | 39,588 | 118 |

실제 학습 대상은 `train.json`, `validation.json`과 `split_manifest.csv`에 남아 있는 이미지입니다. 원본 이미지 폴더에 제외 파일이 남아 있더라도 폴더 전체를 다시 읽어 학습 대상으로 삼지 않습니다.

## 6. 함께 제공하는 CSV

### `legacy_class_exclusion_summary.csv`

데이터 출처와 클래스별 요약표입니다. 총 172행으로 AI hub 116종과 Kaggle Train 56종의 기록을 포함합니다. 두 데이터에 같은 클래스가 있어 행 수는 통합 클래스 수 118종과 다릅니다.

| 열 | 의미 |
|---|---|
| 데이터 | AI hub 또는 Kaggle 데이터 구분 |
| 클래스명 | 공통 약품 코드 |
| 연결된 JSON 개수 | 검증 전 해당 클래스와 연결된 JSON 수 |
| 제외 JSON 수 | 제외 이미지와 연결된 해당 클래스의 JSON 수 |
| 전체 이미지 수 | 검증 전 해당 클래스가 연결된 이미지 수 |
| 제외 이미지 수 | 해당 클래스가 연결된 제외 이미지 수 |
| 유지 이미지 수 | 제외 후 남은 이미지 수 |
| 클래스 전체 제외 | 해당 클래스의 이미지가 모두 제외되었는지 여부 |
| 제외된 사유 | 해당 클래스가 포함된 이미지의 제외 사유 |

제외 수가 0인 클래스도 포함합니다. 이 경우 제외 사유가 비어 있어도 오류가 아닙니다. AI hub는 이미지별 JSON, Kaggle 원본은 알약별 JSON 구조이므로 두 데이터의 JSON 수를 같은 의미의 이미지 수로 해석하지 않습니다.

### `legacy_excluded_image_details.csv`

제외 이미지의 파일명, 클래스, 원본 JSON 경로, 검토 단계와 사유를 확인하는 상세표입니다.

- 총 567행이며, 각 행은 제외 이미지와 클래스·JSON의 연결 기록입니다.
- 이미지 한 장에 여러 클래스가 있으면 파일명이 여러 행에 반복됩니다.
- 이번 자료에서는 상세 행 수가 제외 annotation 수 567개와 일치합니다. 이미지 수는 파일명을 중복 없이 세어야 합니다.
- 클래스별 제외 이미지 수를 합하면 한 이미지가 여러 번 집계되므로 실제 제외 이미지 153장보다 커질 수 있습니다.
- 사유는 해당 이미지의 제외 사유입니다. 그 행에 적힌 클래스의 bbox 자체가 오류였다는 뜻은 아닙니다.

## 7. 기록과 유지 라벨의 일치 확인

제공된 두 CSV와 `train.json`, `validation.json`, `split_manifest.csv`를 비교한 결과입니다.

- 상세표의 제외 이미지는 중복 없이 153장입니다.
- 2차 제외한 5장이 상세표에 모두 포함되어 있습니다.
- 제외 이미지와 유지 라벨의 이미지 목록 사이에 겹치는 파일은 없습니다.
- 클래스별 제외·유지 이미지 수는 요약표와 일치합니다.
- 상세표의 제외 사유에 빈 값은 없습니다.
- 유지 라벨과 분할 목록의 이미지·annotation 수는 위 표와 일치합니다.

이 확인은 제공된 기록과 유지 목록 사이의 일치 여부를 점검한 것입니다. 원본 이미지 전체의 시각적 정확성을 다시 검사한 결과는 아닙니다.

참고로 `K-003351`, `K-003483`은 SELECT 구성 당시 annotation이 없어 SELECT 검증의 제외 클래스로 집계하지 않았습니다. 두 클래스는 대회 Train 데이터에 포함되어 통합 데이터의 118종에 포함됩니다.
